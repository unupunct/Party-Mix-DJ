# Party Mix DJ 1.3.1

Free, dedicated DJ software for the **Numark Party Mix** controller. Windows and macOS (Apple silicon and Intel, macOS 12 Monterey or newer).

## New and fixed
- **macOS installers** (.dmg for Apple silicon and Intel). Built with Electron 43 so they run on Monterey; tested on a 2017 MacBook Air (Intel, macOS 12.7): installs, starts, sees the Party Mix, plays through the Mac speakers with the headphone cue on the controller jack, Auto DJ mixes two tracks.
- **Mac first start**: the master plays on the Mac's own output and the headphone cue goes to the Party Mix headphone jack (before, the sound went to the controller's line outputs and nothing was heard).
- **Auto DJ** now owns the crossfader while it is mixing: the physical crossfader is ignored, so it can no longer pull the next track out of the mix.
- **Controller test** window (Controller test button): a read-only hardware inventory (USB, MIDI ports, audio outputs with Windows volume and mute), recording of every control, LED tests and a probe for unknown LEDs, test tones on the master and the headphones, and a saved report.
- **Headphone cue** to a Party Mix used as a separate output device now goes to channels 3/4 (the headphone jack).

## Known issues
- The HEADPHONE button on some units behaves like a latching switch (ON / OFF on alternate presses); its LED handling is still being investigated.
- If the Party Mix is muted in Windows Sound settings you hear nothing from it: the Controller test shows this.

## Install
Windows: `PartyMixDJ-Setup-1.3.1.exe` (installer) or `PartyMixDJ-1.3.1-portable.exe` (no install). Windows may warn about an unknown publisher (not code-signed): **More info, Run anyway**.
macOS: `PartyMixDJ-1.3.1-mac-arm64.dmg` (M1 and later) or `PartyMixDJ-1.3.1-mac-x64.dmg` (Intel): open it, drag the app to Applications, then right-click it and choose **Open** the first time (the app is not signed or notarised by Apple).
