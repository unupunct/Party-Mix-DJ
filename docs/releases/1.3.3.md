# Party Mix DJ 1.3.3

Free, dedicated DJ software for the **Numark Party Mix** controller. Windows and macOS (Apple silicon and Intel, macOS 12 Monterey or newer).

## Headphones
- **Headphones and speakers in sync**: the engine measures the delay of the headphone output and holds the speakers back by the difference, so both are heard together. New **Headphone sync trim** slider in Audio settings for fine tuning.
- **Clearer, louder headphone sound**: a small jitter buffer removes the gaps between the two audio devices, the volume curve is about twice as loud, and peaks are rounded off instead of hard clipped.
- **HEADPHONE buttons**: off by default; each deck is independent, so you hear only the decks whose button is on (both together if both are on). The master is no longer mixed into the headphones.
- **HEADPHONE lights** go dark with a real note-off message (the controller ignored the old off message), and every press of the latching button counts.
- **Saved audio devices survive a USB port change** (macOS), from 1.3.2.

## Install
Windows: `PartyMixDJ-Setup-1.3.3.exe` or `PartyMixDJ-1.3.3-portable.exe`. macOS: `PartyMixDJ-1.3.3-mac-arm64.dmg` (M1 and later) or `PartyMixDJ-1.3.3-mac-x64.dmg` (Intel); right-click the app and choose Open the first time.
