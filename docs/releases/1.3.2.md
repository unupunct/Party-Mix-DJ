# Party Mix DJ 1.3.2

Free, dedicated DJ software for the **Numark Party Mix** controller. Windows and macOS (Apple silicon and Intel, macOS 12 Monterey or newer).

## Fixed
- **Saved audio devices survive a USB port change** (macOS): the Party Mix headphone cue no longer falls back to off when the controller is plugged into a different port.
- Version 1.3.1 is confirmed on a real Mac: installs, sees the Party Mix, plays through the Mac speakers with the cue on the controller jack, and Auto DJ mixes tracks.

## Install
Windows: `PartyMixDJ-Setup-1.3.2.exe` or `PartyMixDJ-1.3.2-portable.exe`. macOS: `PartyMixDJ-1.3.2-mac-arm64.dmg` (M1 and later) or `PartyMixDJ-1.3.2-mac-x64.dmg` (Intel); right-click the app and choose Open the first time.
